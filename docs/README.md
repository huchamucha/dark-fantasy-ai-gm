# Документация проекта

Этот каталог фиксирует целевую архитектуру универсальной локальной AI RPG-платформы и план её развития.

## Документы

- [Архитектура платформы](ARCHITECTURE.md) — продуктовая концепция, модули, технологии, данные, Story Packs, AI и медиа.
- [План реализации](ROADMAP.md) — этапы разработки и критерии готовности.
- [Технические решения](TECHNICAL_DECISIONS.md) — зафиксированные архитектурные принципы и ограничения.
- [Аудит текущего репозитория](CURRENT_STATE.md) — что уже есть в коде и какие риски нужно закрыть до рефакторинга.

## Важное правило

Документы описывают целевое направление, а не означают, что все перечисленные модули уже реализованы. Реализация проводится постепенно поверх существующего проекта, с проверками после каждого изменения.
